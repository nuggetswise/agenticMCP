# T1.5 Raw X12 panels: contract check and findings, 14 November 2026 (CALLS 69)

## What is built

- **Tools.** Both sides already return a document's raw X12. Ashby gets it from `get_document`, Northfield from `get_document` on its own connection, and the text is the stored interchange (`documents.raw`, cut at 6,000 characters). Smoke covers it: "document carries X12", and "shared X12 is the same on both sides" for ASN-450118-2.
- **Contract check.** `npm run contract` now finds every raw X12 panel in a screen's source. A panel is a run of segments that starts at ISA or ST. It passes only when its segments are a contiguous run of one world document's segments. A panel assembled from page variables cannot be checked and fails as "built on the page". Results are written to `build/contract-report.json`, under `x12_panels` for each prototype.
